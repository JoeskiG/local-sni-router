# Domain IP Override Proxy

A lightweight proxy solution built on mitmproxy to dynamically resolve and override domains to specified IP addresses. Does not require administrator privileges on Windows.

## Prerequisites

Before running the script, ensure you have **Python 3** installed on your system.

## Setup & Installation

1. **Install mitmproxy** via `pip`:
   ```powershell
   pip install mitmproxy
   ```

## Usage

To start the proxy server, execute the launch script inside your PowerShell terminal:

```powershell
./start.ps1
```
